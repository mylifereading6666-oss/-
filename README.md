# フォートナイト精霊チェックリスト

フォートナイトのスプライト／精霊チェックリストを閲覧するための静的ウェブサイトです。

## 使い方
1. GitHub Pages が有効になっている場合は、公開されたサイトの URL を開きます。
2. チェックリスト画面で項目を確認し、サイト内の操作に従って利用してください。

## ソースと変更点
- コピー元: https://github.com/mylifereading6666-oss/fortnite-sprite-checklist
- このリポジトリはコピー元から独立したスナップショットです。
- コピー元のミラー化ワークフローは変更していません。
- このリポジトリにはコピー元の自動ミラー化ワークフローを含めていません。

## ライセンス
コピー元リポジトリにライセンスファイルが見当たらないため、このコピーに新しいライセンスを独自に付与していません。利用・再配布する場合は、元コンテンツの権利者の条件を確認してください。
